# ember-resourcepack
Minecraft Java 26.3 불씨: 일곱 번의 밤 (좀비 협동 생존) 리소스팩 배포

서버가 접속할 때 알아서 받게 하는 팩입니다. 기본 Minecraft 26.3 클라이언트에서 동작합니다. 내려받기는 Releases에 있습니다.
